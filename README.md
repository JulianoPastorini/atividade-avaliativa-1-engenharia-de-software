# 🔐 Minhas Senhas - Gerenciador Local

Uma aplicação web leve e minimalista para armazenamento e gerenciamento de credenciais. O projeto foi desenvolvido com foco em simplicidade e usabilidade, inspirando-se nos guias visuais do Material Design para oferecer uma interface limpa, com navegação intuitiva baseada em cartões (cards) e botões de ação flutuantes.

## ✨ Funcionalidades

- **Cadastro de Credenciais:** Permite salvar o nome do serviço, nome de usuário (ou e-mail) e senha.
- **Visualização em Cartões:** As senhas salvas são exibidas em uma lista de cartões de fácil leitura.
- **Interface Limpa:** Uso de modal flutuante e design focado no conteúdo.
